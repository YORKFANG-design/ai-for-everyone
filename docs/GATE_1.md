# Gate 1：产品定位 + 首页结构

状态：待负责人审核。以下为首版提案，不代表已批准的商业方案。

## 产品定位

面向想用 AI 改善工作与生活、但没有时间研究工具的普通用户，提供短、易懂、能立即实践的每日内容。

首批用户假设：有日常文字处理、信息整理需求的非技术职场用户。先验证这一人群，再评估扩展。

核心承诺：每天几分钟，看懂变化，练会一个技能，发现一个用途。避免承诺收益、效率倍数或保证学习效果。

## 首页顺序

1. 顶部：品牌「人人适用的 AI 订阅」，入口「今日」「往期」「我的收藏」。
2. 首屏标题：「每天几分钟，让 AI 真正帮到你。」副标题：「3 条趋势、1 个小技能、1 个真实用途，从看懂到会用。」按钮：「开始今天的学习」。
3. 今日 3 条趋势：标题、两句解释、与普通人的关系、来源和发布日期。点击查看详情与原始来源。
4. 今日 3 分钟技能：具体任务、所需工具、步骤、可复制提示词、自查标准。「我已练习」记录本机进度。
5. 今日真实用途：使用场景、输入与输出示例、限制和案例依据。
6. 完成状态：今天已练习；引导查看往期、收藏或明天回来。
7. 页脚：内容来源、反馈入口、隐私说明。演示阶段的反馈入口不伪装为已接通服务。

移动端优先；正文清晰、按钮可键盘操作。演示版本显著显示「示例内容，非今日新闻」。

## 首版边界

包含：今日内容、详情、往期、浏览器本地收藏与练习记录、编辑发布流程。

后续评估：账号同步、邮件提醒、会员订阅、真实支付。首版不做算力交易、工具市场、社区或 AI 聊天助手。

## 请审核的三项决定

- 是否接受「普通人每天几分钟学会用 AI」的定位，并优先面向非技术职场用户？
- 是否接受上述首页顺序和 3 + 1 + 1 内容组合？
- 是否同意先验证内容体验与回访意愿，再决定会员价格及收费方式？
